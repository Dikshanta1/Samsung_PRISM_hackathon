# Samsung PRISM Hackathon 2026 — Track 1

Synthetic Eye Movement & Virtual Camera Rendering prototype. Target: reproducible working prototype by 21 November 2026.

## Stage 0 status

The project scaffold is initialized. Blender 5.3.0 is installed and verified for background `bpy` execution. The smoke test creates a sphere, light, and camera, then writes and validates an actual PNG.

## Run the smoke test

```bash
./scripts/run_smoke_test.sh
```

Expected outputs:

- `renders/smoke_test.png` — 256 × 256 PNG, generated by Blender.
- `renders/smoke_test.blend` — saved scene for inspection.

To choose a non-default Blender binary:

```bash
BLENDER_BIN=/absolute/path/to/Blender ./scripts/run_smoke_test.sh
```

## Directories

| Directory | Purpose |
| --- | --- |
| `blender/` | Blender-runtime (`bpy`) modules |
| `wrapper/` | Regular-Python orchestration |
| `scripts/` | Reproducible commands |
| `metadata/` | Frame JSON sidecars |
| `tests/` | Verification scripts |
| `assets/` | Licensed source assets |
| `renders/` | Generated PNGs and `.blend` scenes |
| `outputs/` | Final generated deliverables |
| `docs/` | Supporting design documentation |
